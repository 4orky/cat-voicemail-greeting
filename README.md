## The entry
A voicemail greeting recorded by a cat, in the cat's own voice. `main.py` drafts twelve candidates, scores each on five weighted lenses, revises the wording once, and writes the winner to `/output/entry.txt`:
> "You've reached the cat. I saw you call. I chose not to answer. Leave a message — I'll knock it off the table later."
## Why the winner wins
Twelve drafts were scored on voicemail truth, cat-specific joke, cat voice, spoken delivery, and freshness, weighted 3-3-2-2-1. The winner totals 104; the runners-up 96. What sets it apart:
- It opens like a real voicemail greeting, then the cat confesses it saw the call and chose not to answer.
- The joke is cat through and through: ignoring the caller, then knocking the message off the table.
- It is the cat speaking, not an owner describing a cat: proud, unbothered, a little rude.
- The punch arrives in the last clause, after a beat held by the em dash, so it lands spoken aloud.
- One hundred and fifteen characters, nothing explained, nothing repeated.
## How to run it
Run it with `python3 ./main.py`. The program prints the winning line, writes it to `/output/entry.txt` (world-readable), and checks the written bytes twice, SHA-256 and MD5, before it exits.
